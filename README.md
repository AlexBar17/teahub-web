# TeaHub Web

Веб-интерфейс для TeaHub — приложения для управления каталогом чая.

## Технологии

- React
- TypeScript
- Vite

## Требования

Для локальной разработки необходимы:

- Node.js 22 (рекомендуется 22.23.5)
- npm 10 (проверено на 10.9.9)

## Запуск

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```
